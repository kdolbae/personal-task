# experiments/

**찔러보는 곳.** 될지 안 될지 모르는 것, 하루이틀짜리, 버려도 아깝지 않은 것.

여기는 **코드를 직접 넣어도 된다.** 저장소를 새로 파지 않는다.

새로 만들기: `./new.sh exp <이름>` → `experiments/YYYY-MM-DD-<이름>/`

## 여기서 나가는 두 가지 길

**되겠다 싶으면** → 새 저장소를 파고 코드를 옮긴 뒤 `projects/`에 카드를 만든다.
자세한 절차는 [CONVENTIONS.md](../CONVENTIONS.md) 4번.

**아니다 싶으면** → 결론 한 줄과 배운 것을 적고 `archive/`로 옮긴다.
실패한 실험도 "이건 안 되더라"라는 기록으로 남는다. 지우지 않는다.

## 규칙

- 날짜를 앞에 붙인다. 언제 벌인 일인지가 가장 중요한 정보다
- `.env`는 커밋되지 않는다 (`.gitignore`에 있음). 그래도 키를 코드에 직접 박지 말 것
- 무거운 의존성(`node_modules` 등)은 무시된다
